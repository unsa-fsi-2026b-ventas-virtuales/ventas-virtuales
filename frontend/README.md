# Frontend – React + Vite + TypeScript + Tailwind CSS

Requisitos: Node.js 20+.

```bash
npm create vite@latest frontend -- --template react-ts   # ejecutar desde la raíz del repo
cd frontend
npm install
npm install axios
npm install tailwindcss @tailwindcss/vite
npm run dev
```

Pantallas iniciales: catálogo de productos, carrito, registro de pedido, consulta y seguimiento de pedidos.
